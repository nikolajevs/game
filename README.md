# Мутаген

Браузерная многопользовательская 3D-игра: выживание, стройка базы и рейды
вперемешку с эволюцией собственного существа. Вы появляетесь на большом острове
слабым существом, добываете ресурсы, строите базу, мастерите оружие от копья
до самопала, лезете за добычей в радиационные руины и копите ДНК, чтобы
отрастить ноги, когти, рога, панцирь или кислотную железу.

## Запуск

Нужен Node.js 18 или новее.

```bash
npm install
```

```bash
npm start
```

Откройте http://localhost:3000. Чтобы играть с друзьями в одной сети, им
нужно открыть `http://<IP вашего компьютера>:3000`.

Превью мира без входа в игру: http://localhost:3000/preview.html

Настройки через переменные окружения:

| Переменная | Что делает |
|---|---|
| `PORT` | порт сервера (по умолчанию 3000) |
| `SEED` | зерно генерации острова для нового мира |
| `FRESH=1` | начать новый мир, не загружая сохранение («вайп») |

Мир (постройки, геномы и инвентарь игроков) сохраняется в `data/world.json`
каждые 30 секунд и при остановке сервера через Ctrl+C. Если сохранение сделано
для острова другого размера, постройки сбрасываются, а геномы и вещи игроков
переносятся на новый остров.

## Управление

| Клавиша | Действие |
|---|---|
| W A S D | идти (относительно камеры), Shift — бег |
| Курсор мыши | прицел: существо бьёт, плюётся и таранит в точку под курсором |
| ЛКМ | удар или выстрел выбранным оружием: бьёт существ, рубит деревья, камни, кусты, ломает постройки |
| 1–9 | взять оружие из пояса (повторное нажатие — убрать) |
| C | меню крафта |
| Q или щелчок ПКМ | плевок кислотой (если есть кислотная железа) |
| Пробел | таран в сторону курсора (если есть рога) |
| Потянуть мышью с зажатой ЛКМ, ПКМ или средней кнопкой; ← → ↑ ↓ | вращать камеру (щелчок ЛКМ без движения — удар) |
| M | звук вкл/выкл |
| Колесо | отдалить / приблизить камеру |
| E | пить у воды, открыть хранилище, ящик с добычей, обыскать останки |
| F | съесть лучшую для вашего рта еду |
| R | принять антирад |
| B, затем 1–8 | режим стройки и выбор постройки: призрак идёт за курсором в пределах зелёного круга; ЛКМ — поставить, ПКМ — отмена |
| X | снести свою постройку под курсором (вернётся половина ресурсов) |
| G | редактор генома |
| Tab | список игроков |
| Enter | чат |
| H | скрыть подсказку по управлению |

## Как устроена игра

**Выживание.** Голод и жажда растут постоянно. Пить — у воды (E), есть — ягоды
и мясо (F). Если они на нуле, существо теряет здоровье. У костра здоровье
восстанавливается быстрее.

**Смерть.** Всё, что вы несли, и 30% непотраченной ДНК остаются в останках,
их может забрать кто угодно. Геном (части тела) сохраняется. Возрождение —
в своём гнезде или на случайном берегу.

**Эволюция.** ДНК даётся за еду, добычу кристаллов и убийство диких существ.
За неё в редакторе (G) выбирается рот (травоед, хищник, всеядный) и части тела
с уровнями 1–3. Третий уровень требует кристаллов мутагена. Суммарная
сложность ограничена 12 уровнями, поэтому приходится выбирать специализацию.
Удалённые части возвращают половину ДНК. В бою эволюционировать нельзя.

| Часть | Эффект |
|---|---|
| Ноги | скорость |
| Когти | урон и добыча |
| Панцирь | здоровье и защита, но медленнее |
| Шипы | отражают урон в ближнем бою |
| Глаза | дальность обзора (и ночью) |
| Рога | таран, хорошо ломает постройки |
| Кислотная железа | дальняя атака, замедляет |
| Плавники | быстрое плавание |
| Биолюминесценция | свечение ночью (вас тоже видно) |
| Желудок | медленнее голод и жажда |
| Масса тела | больше здоровья и урона, но крупнее и медленнее |
| Радиорезистентность | радиация копится медленнее (−30% за уровень) |

**Оружие и крафт.** Оружие мастерится в меню крафта (C) из ресурсов и держится
когтями: без когтей его не взять. При смерти оружие остаётся в останках вместе
с остальными вещами.

| Ступень | Оружие | Из чего |
|---|---|---|
| 1 | дубина, копьё, каменный топор (рубит вдвое быстрее), праща (стреляет камнями) | дерево, камень |
| 2 | костяной клинок, кирка (камень, сера и металл вдвое быстрее), лук, арбалет | + кости, металлолом |
| 3 | самопал, дробовик, взрывпакет (рушит стены) | металлолом и сера, только у верстака |

Стрелы делаются из дерева и камня, патроны — из металлолома и серы у верстака.
Кости дают убитые существа, серу — жёлтые валуны в скалах, металлолом — руины.

**Радиация.** На острове несколько радиационных зон — руин с разрушенным
реактором (на карте они жёлто-зелёные, со знаком ☢). Внутри облучение растёт,
быстрее у центра; выше 25 здоровье не восстанавливается, выше 50 начинает
падать. Снаружи радиация медленно спадает, антирад (R) снимает её сразу.
Зато в руинах лежат груды металлолома и ящики с добычей (металлолом, сера,
патроны, антирад, иногда арбалет, самопал, дробовик или взрывпакет), а
охраняют их мутанты. Свежая воронка метеорита тоже фонит.

**Стройка и рейды.** Постройки занимают клетку сетки: стены из ветвей и
камня, дверь (проходит только владелец), хранилище, костёр, колья, гнездо,
верстак. Любую постройку можно разрушить ударами, плевками, тараном и
взрывпакетами; каменные стены держатся заметно дольше. Содержимое
разрушенного хранилища высыпается.

**Мир.** Остров 9600×9600 единиц. День сменяется ночью (цикл 7 минут). Ночью
темнее и опаснее: клыкачей становится больше, и они замечают вас издалека.
Травники убегают, колоссы охраняют свою территорию. Раз в несколько минут
падает метеорит: место отмечено на карте и лучом в небе, там появляются
кристаллы мутагена и агрессивные мутанты.

## Архитектура

- **Сервер** (`server/`) — Node.js + `ws`. Он единственный источник правды:
  считает движение, столкновения, бой, ИИ, стройку и эволюцию 30 раз в секунду
  на плоской карте и рассылает каждому игроку то, что тот видит.
- **Клиент** (`public/`) — Three.js. Рисует 3D-мир и интерполирует движение
  других существ между снимками сервера. Высоты рельефа чисто визуальные.
- **Общий код** (`shared/`) — правила, баланс, геном и генерация острова.
  Используется и сервером, и браузером.

```
server/
  index.js       HTTP + WebSocket, такт симуляции, автосохранение
  game.js        вся игровая логика
  ai.js          поведение диких существ
  world.js       пространственная сетка
  static.js      раздача файлов
  persist.js     сохранение мира
shared/
  config.js      константы и баланс: оружие, рецепты, радиация, существа
  creature.js    геном: кодирование, стоимость, характеристики
  worldgen.js    генерация острова, радиационных зон и ресурсов
public/
  index.html, style.css
  preview.html   превью мира без сервера игры
  js/main.js     клиент: вход, сеть, ввод, стройка
  js/world3d.js  3D-сцена игры
  js/hud.js      интерфейс: полоски, пояс оружия, крафт, мини-карта
  js/editor.js   редактор генома
  js/input.js    клавиатура, мышь, камера
  js/gfx/        рельеф, небо, деревья и постройки, существа, оружие,
                 радиационные зоны, эффекты, декор
```

Баланс (урон оружия, рецепты, сила радиации, цены мутаций, число существ)
меняется в `shared/config.js`.
