# Мутаген

Браузерная многопользовательская 3D-игра: выживание, стройка базы и рейды
вперемешку с эволюцией собственного существа. Вы появляетесь на острове
слабым существом, добываете ресурсы, строите базу и копите ДНК, чтобы
отрастить ноги, когти, рога, панцирь или кислотную железу.

## Запуск

Нужен Node.js 18 или новее.

```bash
npm install
```

```bash
npm start
```

Откройте http://localhost:3000. Чтобы играть с друзьями в одной сети, им
нужно открыть `http://<IP вашего компьютера>:3000`.

Превью мира без входа в игру: http://localhost:3000/preview.html

Настройки через переменные окружения:

| Переменная | Что делает |
|---|---|
| `PORT` | порт сервера (по умолчанию 3000) |
| `SEED` | зерно генерации острова для нового мира |
| `FRESH=1` | начать новый мир, не загружая сохранение («вайп») |

Мир (постройки, геномы и инвентарь игроков) сохраняется в `data/world.json`
каждые 30 секунд и при остановке сервера через Ctrl+C.

## Управление

| Клавиша | Действие |
|---|---|
| W A S D | идти (относительно камеры), Shift — бег |
| Мышь | вращать камеру (щёлкните по экрану, чтобы захватить мышь) |
| Колесо | отдалить / приблизить камеру |
| ЛКМ | удар: бьёт существ, рубит деревья, камни, кусты, ломает постройки |
| ПКМ | плевок кислотой (если есть кислотная железа) |
| Пробел | таран (если есть рога) |
| E | пить у воды, открыть хранилище, обыскать останки |
| F | съесть лучшую для вашего рта еду |
| B, 1–7 | режим стройки и выбор постройки; ЛКМ — поставить, ПКМ — отмена |
| X | снести свою постройку под прицелом (вернётся половина ресурсов) |
| G | редактор генома |
| Tab | список игроков |
| Enter | чат |
| H | скрыть подсказку по управлению |

## Как устроена игра

**Выживание.** Голод и жажда растут постоянно. Пить — у воды (E), есть — ягоды
и мясо (F). Если они на нуле, существо теряет здоровье. У костра здоровье
восстанавливается быстрее.

**Смерть.** Всё, что вы несли, и 30% непотраченной ДНК остаются в останках,
их может забрать кто угодно. Геном (части тела) сохраняется. Возрождение —
в своём гнезде или на случайном берегу.

**Эволюция.** ДНК даётся за еду, добычу кристаллов и убийство диких существ.
За неё в редакторе (G) выбирается рот (травоед, хищник, всеядный) и части тела
с уровнями 1–3. Третий уровень требует кристаллов мутагена. Суммарная
сложность ограничена 12 уровнями, поэтому приходится выбирать специализацию.
Удалённые части возвращают половину ДНК. В бою эволюционировать нельзя.

| Часть | Эффект |
|---|---|
| Ноги | скорость |
| Когти | урон и добыча |
| Панцирь | здоровье и защита, но медленнее |
| Шипы | отражают урон в ближнем бою |
| Глаза | дальность обзора (и ночью) |
| Рога | таран, хорошо ломает постройки |
| Кислотная железа | дальняя атака, замедляет |
| Плавники | быстрое плавание |
| Биолюминесценция | свечение ночью (вас тоже видно) |
| Желудок | медленнее голод и жажда |
| Масса тела | больше здоровья и урона, но крупнее и медленнее |

**Стройка и рейды.** Постройки занимают клетку сетки: стены из ветвей и
камня, дверь (проходит только владелец), хранилище, костёр, колья, гнездо.
Любую постройку можно разрушить ударами, плевками и тараном; каменные стены
держатся заметно дольше. Содержимое разрушенного хранилища высыпается.

**Мир.** День сменяется ночью (цикл 7 минут). Ночью темнее и опаснее:
клыкачей становится больше, и они замечают вас издалека. Травники убегают,
колоссы охраняют свою территорию. Раз в несколько минут падает метеорит:
место отмечено на карте и лучом в небе, там появляются кристаллы мутагена
и агрессивные мутанты.

## Архитектура

- **Сервер** (`server/`) — Node.js + `ws`. Он единственный источник правды:
  считает движение, столкновения, бой, ИИ, стройку и эволюцию 30 раз в секунду
  на плоской карте и рассылает каждому игроку то, что тот видит.
- **Клиент** (`public/`) — Three.js. Рисует 3D-мир и интерполирует движение
  других существ между снимками сервера. Высоты рельефа чисто визуальные.
- **Общий код** (`shared/`) — правила, баланс, геном и генерация острова.
  Используется и сервером, и браузером.

```
server/
  index.js       HTTP + WebSocket, такт симуляции, автосохранение
  game.js        вся игровая логика
  ai.js          поведение диких существ
  world.js       пространственная сетка
  static.js      раздача файлов
  persist.js     сохранение мира
shared/
  config.js      константы и баланс
  creature.js    геном: кодирование, стоимость, характеристики
  worldgen.js    генерация острова и ресурсов
public/
  index.html, style.css
  preview.html   превью мира без сервера игры
  js/main.js     клиент: вход, сеть, ввод, стройка
  js/world3d.js  3D-сцена игры
  js/hud.js      интерфейс
  js/editor.js   редактор генома
  js/input.js    клавиатура, мышь, камера
  js/gfx/        рельеф, небо, деревья и постройки, существа, эффекты, декор
```

Баланс (урон, цены, скорость голода, число существ) меняется в
`shared/config.js`.
